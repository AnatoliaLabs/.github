## 🐺 Anatol-X

Anatol-X is a Debian-based Linux distribution we are developing for
gaming, productivity, and everyday use.

The current ISO configuration includes:

- **Debian 13 Trixie** as its foundation
- **KDE Plasma 6**, with Wayland as the default session
- The **Liquorix** kernel
- **Anatolium**, the system browser
- A signature-verified **Anatol-X APT repository**

🚧 **Anatol-X is in development. A public stable release is coming soon.**

[Explore Anatol-X →](https://anatolialabs.github.io/Anatol-X/)  
[View the source repository →](https://github.com/AnatoliaLabs/Anatol-X)

> Hardware and driver compatibility should be tested. The Liquorix
> kernel is not signed for standard Secure Boot; disabling Secure Boot
> may be necessary without a suitable custom signing setup.
